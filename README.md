# Zhi-Qiang Liu — Personal Website

Personal website and CV, published with GitHub Pages.

**Website:** https://liuzq1103.github.io/

## Structure

- `index.html` — bilingual personal homepage: profile, research interests, selected publications, and selected software projects.
- `cv.html` — browser-based CV viewer and PDF download.
- `style.css` — responsive visual system.
- `assets/people/liuzq.jpeg` — profile photo.
- `assets/people/liuzq_cv.pdf` — current CV PDF stored in this repository.

## Updating content

Edit the relevant section in `index.html`. Chinese and English copy are paired using `data-lang="zh"` and `data-lang="en"`.

To replace the CV, upload the new PDF to `assets/people/liuzq_cv.pdf` and keep the filename unchanged, or update the links in `cv.html` and `index.html`.

The legacy lab-template pages redirect to the corresponding section of the personal homepage.
